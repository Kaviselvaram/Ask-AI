# Verification Benchmark Tests

This document outlines the benchmark test cases for the new Verification Intelligence layer.

## Test Case 1: Supported Answer

**Question:** What is AIOS?
**Expected Result:**
- **Confidence:** >= 0.8
- **Explanation:** The evidence supports the facts stated in the answer.
- **Action:** Answer is accepted and returned unmodified.

---

## Test Case 2: No Evidence

**Question:** Who founded AIOS?
**Scenario:** If no evidence exists in the uploaded context.
**Expected Result:**
- **Confidence:** < 0.5
- **Explanation:** Claims about the founder are not found in the evidence.
- **Action:** Verification must reject the unsupported answer. System falls back to `SafeAnswer` indicating lack of supporting evidence.

---

## Test Case 3: Comparison Claims

**Question:** Compare AIOS and Moodle.
**Expected Result:**
- **Confidence:** >= 0.8 (assuming the context contains the necessary comparison points).
- **Explanation:** The specific comparison points generated by the LLM match the facts retrieved.
- **Action:** Answer is accepted.

---

## Test Case 4: Hallucination Prevention

**Question:** What is Elon Musk's favorite food?
**Scenario:** No evidence exists in the vault. The LLM might try to hallucinate.
**Expected Result:**
- **Confidence:** 0.0
- **Explanation:** The context does not mention Elon Musk or his favorite food.
- **Action:** Verification should detect zero support and replace the hallucination with a safe fallback answer.

---

## Test Case 5: Incorrect Intentional Answer

**Scenario:** Inject an intentionally incorrect answer into the pipeline and test the verification service.
**Expected Result:**
- **Confidence:** < 0.5
- **Explanation:** The generated facts contradict the retrieved evidence.
- **Action:** Verification should detect the unsupported claims and prevent the hallucinated answer from reaching the user.
